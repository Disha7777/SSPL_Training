# E-Learning UI Project

## Overview
This project is an E-Learning UI application that provides users with a platform to browse and enroll in various courses. The application features a clean and responsive design, utilizing modern web technologies such as HTML, CSS, jQuery, and AJAX.

## Project Structure
```
e-learning-ui
├── css
│   └── style.css
├── js
│   └── script.js
├── data
│   └── prompts.txt
├── index.html
└── README.md
```

## Features
- **Course Cards**: Display a list of available courses with essential information.
- **Search/Filter Functionality**: Users can search for courses by name or category.
- **Course Details Modal**: Clicking on a course card opens a modal with detailed information about the course.
- **Enrollment Form**: Users can enroll in courses through a form that submits data via AJAX.

## Technologies Used
- **HTML**: For structuring the content.
- **CSS**: For styling the application, including responsive design.
- **jQuery**: For DOM manipulation and AJAX requests.
- **Fetch API**: To load course data from an external API.

## Setup Instructions
1. Clone the repository to your local machine.
2. Open `index.html` in a web browser to view the application.
3. Ensure you have an internet connection to fetch course data from the API.

## Additional Notes
- The application is designed to be responsive and should work well on both desktop and mobile devices.
- Future enhancements may include user authentication, user profiles, and additional course management features.
